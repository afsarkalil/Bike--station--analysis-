# 🚲 Bike Station Analysis | Power BI Dashboard

## 📌 Project Overview

This project focuses on analysing Bike Sharing Station data using Microsoft Power BI. The main objective is to analyse bike station information, identify open and closed stations, and present meaningful insights through an interactive dashboard.

The dashboard helps users understand station availability and explore station information through different visualisations.

## 🎯 Project Objectives

- Analyse bike-sharing station data.
- Identify the total number of stations.
- Analyse open and closed station counts.
- Compare station availability.
- Create an interactive Power BI dashboard.
- Generate meaningful insights for better decision-making.

## 🔍 Analysis Types

### 1. Descriptive Analysis
- What is the total number of bike-sharing stations?
- How many stations are open?
- How many stations are closed?

### 2. Diagnostic Analysis
- Why are some stations closed?
- Which categories have more closed stations?
- What patterns can be identified in station availability?

### 3. Predictive Analysis
- What could future station availability look like?
- Which stations may require attention based on historical patterns?

### 4. Prescriptive Analysis
- Which stations should be prioritised for maintenance?
- How can station availability be improved?
